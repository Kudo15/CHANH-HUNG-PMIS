## Dispatch controls
- Required prompt template for worker tasks: locate and retrieve a task-specific template through installed `.agents/skills/prompt-lookup`; templates and adaptations are recorded in the task pack and ledger.
- Role routing: Worker and Reviewer use explicit Hermes CLI Kanban cards; independent Tester/Verifier uses the OpenCode shared background service with `role-verifier`, read-only scope, and OpenCode's configured default model; planner/coordinator/other roles inherit Codex's configured default. All dispatch remains explicit (`autoDispatch=false`, `autoRun=false`).
- Serialize Worker → OpenCode Tester → Hermes Reviewer against the current checkout. Do not assume a clean worktree while the frontend/backend baseline is untracked.
- No task is allowed to change stack, deploy, use real agency data, or bypass a Human Gate.
- Update `.team/ledger.md` for every task with harness/model/provider/profile/effort only when observed; otherwise use `NEEDS_HUMAN_SELECTION`.
